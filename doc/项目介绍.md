# BMC AutoInsight — 项目介绍

## 定位

**BMC AutoInsight** 是一款面向数据中心与实验室的 **Redfish 带外运维工具**，以 Python 实现。它帮助运维、测试工程师在 **不依赖厂商专用客户端** 的前提下，完成 BMC 连通性验证、硬件与固件信息采集、温度/风扇/功耗等巡检、规则化告警、API 冒烟测试及受控的远程电源操作。

## 核心功能

| 功能 | 说明 |
|------|------|
| 服务器硬件信息查询 | 汇总服务器硬件信息与 **BIOS / BMC 固件版本**，并涵盖 CPU、内存、硬盘等相关资源（详见 `hardware-info`） |
| 电源控制 | 远程 **开机 / 关机 / 重启**，支持 **安全确认**（如 `--confirm`）与 **`dry_run` 默认**，降低误操作风险 |
| API 自动化冒烟测试 | Redfish **GET** 连通性校验（期望 **HTTP 200**），自动发现并执行用例，结果可写入巡检 HTML 报告（`api-test` 或集成巡检） |
| 历史报告自动清理 | **`clean-reports`**：按导出时间戳归组清理 `reports/` 下历史文件，支持 **`--keep` 指定保留批次**、**`--dry-run` 仅预览** |

## 适用场景

| 场景 | 说明 |
|------|------|
| 交付验收 | 批量或单机拉取硬件/固件基线，导出 HTML/Excel 留档 |
| 日常巡检 | `inspect` / `fault-check` 定期执行，结合阈值发现异常 |
| 变更前检查 | `power-status`、`hardware-info` 快速确认状态与版本 |
| 接口可用性 | `api-test` 自动发现 URI 并做 GET 200 冒烟 |
| 离线演示 | `--mock` 使用本地夹具，无需真实 BMC |

## 技术特点

- **多厂商 Redfish**：在超微、戴尔、HPE、浪潮等常见实现上尽量做兼容与回退（如事件日志路径探测、存储 403 说明）。
- **安全默认**：电源变更需确认；默认 `dry_run` 防误操作；敏感配置建议不入库。
- **可观测输出**：JSON / HTML / TXT / XLSX 多格式报告；日志可落盘。
